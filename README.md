# Golden Gate — an Omarchy theme

A macOS-inspired dark theme for [Omarchy](https://omarchy.org), dressed in the Golden Gate's
International Orange. Built on [Cupertino](https://github.com/pavandot/omarchy-cupertino-theme):
same Liquid Glass and macOS feel, with a San Francisco sunset palette.

![Golden Gate preview](preview.png)

- **International Orange accent** `#ec5a2c`: selected menu rows, focus rings, active workspace, keyboard backlight
- **Fog-tinted Pacific navy** surfaces (`#1b1d26`) with warm fog-white text, instead of neutral grey
- **Apple dark-mode system colours** for the terminal palette, with a sunset-gold yellow
- **Hairline window edges** with a warm, sunset-lit top-left highlight instead of bold coloured borders
- **macOS-style menus**: solid orange selected row with white text, a light Spotlight-like dim behind menus
- **Liquid Glass** (optional, one command): frosted, translucent bar, menus, launcher, notifications and popovers, soft window shadows, 10px squircle corners
- **Yaru** icons (orange folders)
- **Original wallpaper**: the bridge at sunset with fog rolling under the deck, generated by `extras/make-wallpaper.py`

## Install

```bash
omarchy theme install https://github.com/pavandot/omarchy-golden-gate-theme
```

### Enable Liquid Glass (recommended)

Themes installed from git can't ship Hyprland config, so the glass blur, shadows,
1px borders and rounded corners come as a one-time opt-in:

```bash
~/.config/omarchy/themes/golden-gate/extras/install-glass.sh
```

This copies `extras/golden-gate-glass.lua` to `~/.config/hypr/` and adds
`require("hypr.golden-gate-glass")` to `~/.config/hypr/hyprland.lua`. It stays active
across theme changes; to turn it off, delete that line. If you already enabled
Cupertino's glass, you don't need this: the two are identical.

## Files

| File | Purpose |
|------|---------|
| `colors.toml` | Palette and window border colours; Omarchy generates terminal, editor and app themes from it |
| `shell.*.toml` | Bar, menu, launcher, popups, tooltips, notifications, lock screen, password prompt, controls |
| `icons.theme` | Yaru (orange) icons |
| `keyboard.rgb` | Keyboard backlight colour (supported laptops) |
| `backgrounds/` | Wallpaper |
| `extras/` | Liquid Glass module + installer, wallpaper generator |

## Tuning

- Translucency: lower `background-alpha` in `shell.menu.toml`, `shell.launcher.toml`,
  `shell.popups.toml`, `shell.notifications.toml`, `shell.bar.toml` for more glass
- Frost: `blur.size` / `blur.passes` in `~/.config/hypr/golden-gate-glass.lua`
- Re-apply after editing theme files: `omarchy theme set golden-gate`

## Wallpaper

Drawn entirely in code (no photos), so it is free to share under this repo's licence:
